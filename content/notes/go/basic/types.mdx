<!-- Number Types -->

<UnportedShortcode source={"{{< note title=\"Numbers\" >}}"} />

Typical types

```go
num := 3          // int
num := 3.         // float64
num := 3 + 4i     // complex128
num := byte('a')  // byte (alias for uint8)
```

Other Types

```go
var u uint = 7        // uint (unsigned)
var p float32 = 22.7  // 32-bit float
```
